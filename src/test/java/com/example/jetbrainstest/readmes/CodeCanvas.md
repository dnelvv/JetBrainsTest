**Кейс 1: Переход на страницу новостей с ожиданием URL**
**ШВ:**
1) Открыть https://www.jetbrains.com/codecanvas/
2) Кликнуть на кнопку "Blog" в навбаре
3) Кликнуть на кнопку "News"

**ОР:** Открывается страница с новостями
